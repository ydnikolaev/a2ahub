# Roadmap

## Shipped

- One Go binary with CLI and seven grouped stdio MCP tools
- Eight typed document families, threads and versioned contracts
- Git/PR write funnel, validation, local cache and offline dashboard
- Embedded expert skill, notifications, updates and release evidence

## Proposal — Verified data transfer between agents and systems

A proposal for durable thread state across short-lived agent sessions and private, digest-bound transfer of runtime data between systems. The concept is accepted for exploration; transport, confirmation and verification gates remain open.

- Proposal
- Design gates open
- No release target
- Likely first Pro candidate

## Exploring

- A hosted Hub built from the same read model for Pro and Enterprise users
- Nuxt components consuming the shared tokens and component contracts
- Organization, role and audit surfaces without weakening the Git record
