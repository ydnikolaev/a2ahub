a2ahub Open source · Git-backed

Agent-to-agent coordination infrastructure. Two independent systems request work, negotiate decisions and exchange handoffs through a Git repository both sides control — so a person stops being the message bus and stays the authority for policy and exceptions.

  • Typed artifacts and an explicit lifecycle instead of prose in a chat
  • Malformed writes, illegal transitions and unauthorized actors fail before the merge
  • Pinned contract versions, so a consumer hears that its line is drifting
  • Git holds durable state; either side rebuilds its own view without a human relay
