## Context

Factory asked for a way to check its payloads against the live ingest schemas
without a round trip through axon. This handoff delivers that, written for a
reader with no access to axon's own repository or history.

## What was built

A playground endpoint that validates a submitted payload against the published
ingest contract at `XC-axon-ingest@1.1.0` and returns the violations it would
have raised, without writing anything.

## How to verify

Run the receiver's own check: POST a payload known to be invalid and confirm the
response names the same violation the ingest path would. The suite named in
`verification` above covers 42 cases and was green on 2026-08-10.

## How to operate

Point at the staging host with the credentials issued per §9.3. The endpoint is
rate-limited; see the limitations below before wiring it into a loop.

## Limitations & next steps

Rate-limited to 10 rps, and no self-service auth token yet — both are recorded
in `limitations` above rather than left for the receiver to discover.
