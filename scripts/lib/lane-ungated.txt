# The explicit list of repo paths NO declared gate claims, on purpose. A
# path lands here only after checking every real declaration and finding
# none reads it — never as a way to silence a refusal that just hasn't been
# investigated yet.
#
# `go run internal/lane/lanecheck.go --verify` (wrapped by
# scripts/check-lane-declarations.sh) reads this file relative to LANE_ROOT
# (default: repo root). Its absence is NOT an error — an empty ungated list
# is the correct starting point, not a missing dependency (see
# lanecheck.go's readUngatedList).
#
# Format: one repo-relative glob per line (the same grammar
# internal/lane/glob.go's Match uses — "**" crosses path separators,
# everything else is single-segment). "#" starts a comment; blank lines are
# ignored. Every entry REQUIRES a reason: put it as a "#" comment on the
# line directly ABOVE the glob it explains, e.g.:
#
#   # Swift package; no gate in this repo's make-ABI reads it.
#   integrations/macos-notifier/**
#
# This file intentionally ships EMPTY at the end of P12/W2. The lead
# adjudicates the coverage residue inline (plan D-6) before populating it —
# an agent filling this in on day one is how the gate goes toothless on
# arrival, which is explicitly not this session's call to make.
