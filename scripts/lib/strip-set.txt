# strip-set.txt — THE publish boundary's private path set. ONE definition.
#
# Every path listed here is REMOVED from every commit of the public product
# history by docs/runbooks/publish-to-public.sh. Four readers, zero copies:
#
#   docs/runbooks/publish-to-public.sh   builds STRIP=( --path X ... ) from it
#   scripts/classify-guard.sh            derives PRIVATE_ONLY_FILES from it
#   .github/workflows/classify-guard.yml derives its denylist regex from it
#   scripts/check-projection.sh          removes exactly these from the projection
#
# It lives here, and it SHIPS, because the workflow above is the one reader
# that only ever runs on the PUBLIC checkout — where the publisher, living
# under docs/, has been stripped by the very filter that backstop double-
# checks. Before this file the workflow had nothing present at runtime to
# derive from and carried a hand-typed regex that had already drifted by five
# of six entries. Shipping the list is not a leak: scripts/classify-guard.sh
# already ships and already carries these names.
#
# FORMAT — parsed identically by all four readers:
#   * one path per line, repo-relative;
#   * a trailing "/" means a DIRECTORY and matches its whole subtree;
#   * anything else is a FILE and is anchored exactly, which is what keeps
#     .github/dependabot.yml from matching the space-template's own
#     dependabot.yml at a different path;
#   * a line whose first non-blank character is "#" is a comment; blank lines
#     are ignored.
#
# AN EMPTY OR UNREADABLE LIST IS NEVER "NOTHING TO STRIP". Every reader
# refuses loudly on it: for the publisher an empty set means git filter-repo
# strips nothing and force-pushes the private tree, and for the gates it means
# a projection identical to its source, which proves nothing while looking
# green.
